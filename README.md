# CHO CLI

The command-line tool for [CHO](https://github.com/cho-js/cho), built with
[`@chojs/command`](https://jsr.io/@chojs/command).

## Workspaces

| Workspace      | Package      | What it is                         |
| -------------- | ------------ | ---------------------------------- |
| [`bin`](./bin) | `@chojs/cli` | The `cho` command-line application |

## Development

```sh
deno task cho --help   # run the CLI
deno task test         # run the tests
```
